# Alcance

## Alcance del Sistema

* **Gestión de Clientes:** Módulo para el registro obligatorio y mantenimiento (CRUD) de clientes con datos personales estrictos para validación de garantías.
* **Gestión de Inventario (Catálogo y Stock):** Administración centralizada de productos (insumos, componentes, herramientas). Incluye la vinculación exclusiva de cada producto con su proveedor y la actualización automatizada del stock.
* **Gestión de Servicios Técnicos:** Módulo operativo para la creación de órdenes de reparación, registro del equipo, falla reportada, asignación de un único técnico responsable y carga de insumos utilizados.
* **Módulo de Ventas y Facturación (Caja):** Generación de comprobantes (tickets) unificados tanto para ventas de mostrador como para el cobro de reparaciones finalizadas. Incluye el registro histórico de precios y la gestión de cobros con múltiples métodos de pago.
